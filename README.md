# Ramadan Mubarak Animated Greeting Page

A simple and beautiful **Ramadan Mubarak greeting webpage** built with **HTML, CSS, and JavaScript**. The page includes an animated particle background, a moving mosque silhouette, and a festive Ramadan message.

## 🌙 Project Overview

This project is a static web page designed to share Ramadan greetings in a visually attractive way. It can be used as a personal greeting page, social media landing page, or small seasonal web project.

## ✨ Features

- Full-screen Ramadan greeting design
- Animated mosque background
- Particle animation effect using JavaScript
- Gradient background
- Responsive full-page layout
- Lightweight static website
- Easy to customize text, colors, and images

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Particles.js animation
- Google Fonts

## 🧩 How It Works

- `index.html` contains the main greeting text and layout.
- `style.css` controls the page design, gradient background, text styling, mosque animation, and positioning.
- `particles.js` provides the particle animation engine.
- `app.js` configures the particle behavior such as number, size, speed, direction, and click interaction.
- `mosque.png` is used as the animated mosque background.

## 🎨 Customization

### Change the greeting text

Edit the text inside `index.html`:

```html
<h1><span>from Arfan</span></h1>
<h2>Ramadan Mubarak</h2>
<h3>To You & Your Family!</h3>
```

### Change background colors

Edit the gradient inside `style.css`:

```css
background: linear-gradient(#ffeb3b, #e91e63);
```

### Change particle settings

Edit the particle configuration inside `app.js`:

```js
"number": {
  "value": 40
},
"move": {
  "speed": 6,
  "direction": "top"
}
```

## 🌐 Deployment

This project can be deployed easily using:

1. Upload the files to a GitHub repository.

4. Save the settings.
